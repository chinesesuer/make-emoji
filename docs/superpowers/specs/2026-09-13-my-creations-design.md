# 我的制作云端作品库设计

## 目标

用户在首页“存表情”中点击生成并完成登录后，生成结果自动保存到个人作品库。个人中心的“我的制作”入口展示当前微信用户最近制作的表情，点击作品可预览大图。视觉内容相同的作品只保留最新一条记录。

## 范围

- 首页生成成功后自动保存作品。
- 使用微信云存储保存成品图片，使用 `creations` 集合保存作品元数据。
- 新增“我的制作”列表页，最多展示最近更新的 50 条作品。
- 点击列表中的图片调用 `wx.previewImage` 查看。
- 首版不提供删除、分享或分页操作。

## 客户端流程

### 生成与保存

1. `generateEmoji()` 沿用现有登录门禁和画布导出流程。
2. 画布导出成功后，立即显示生成结果，确保云端保存失败不影响用户本次生成。
3. 根据当前画布的视觉状态构造规范化对象，包括身体、表情、挂件的素材标识、位置与缩放旋转翻转，文字内容与样式，以及透明背景、尺寸和质量设置。
4. 对规范化 JSON 计算稳定内容指纹。同一视觉配置始终得到相同指纹，不包含生成时间或本地临时路径。
5. 将生成图片上传至 `user-creations/<openid>/<fingerprint>-<timestamp>.<ext>`。
6. 调用 `quickstartFunctions` 的 `saveCreation`，传入新文件 ID、指纹和允许保存的输出信息。
7. 保存失败时保留生成结果弹窗，并显示“作品保存失败，请稍后重试”。

### 我的制作

1. 个人中心“我的制作”在统一登录门禁成功后跳转到 `pages/myCreations/myCreations`。
2. 页面显示时调用 `quickstartFunctions` 的 `listCreations`。
3. 云函数按可信 OPENID 查询，按 `updatedAt` 倒序返回最多 50 条记录。
4. 页面批量调用 `wx.cloud.getTempFileURL` 获取可展示地址。
5. 点击任一作品调用 `wx.previewImage`，并传入当前作品地址和列表地址。
6. 加载中、空列表和加载失败均显示明确状态；失败支持点击重试。

## 云端接口与数据模型

`quickstartFunctions` 新增两个事件：

- `saveCreation`: 保存或更新当前用户的一条作品。
- `listCreations`: 返回当前用户最近更新的作品列表。

云端身份只取 `cloud.getWXContext().OPENID`，忽略客户端提供的任何用户身份字段。

`creations` 记录字段：

```js
{
  _openid: String,
  fingerprint: String,
  fileID: String,
  fileType: 'png' | 'jpg',
  createdAt: Date,
  updatedAt: Date
}
```

`saveCreation` 校验指纹格式、云文件 ID 与文件类型。云端使用 Node.js 内置 `crypto` 对可信 OPENID 和指纹计算确定性记录 ID，避免同一用户、同一内容在并发请求下产生重复记录：

- 该记录不存在：使用确定性 ID 创建记录。
- 该记录已存在：用新文件 ID 更新原记录和 `updatedAt`，保留 `createdAt`。
- 更新成功且旧文件 ID 与新文件不同：尝试删除旧云文件；删除失败不回滚已保存的新记录。
- `creations` 集合不存在时，由云函数自动创建并重试，处理并发首次创建。

`listCreations` 不接受客户端 OPENID，固定返回当前用户最多 50 条记录。返回字段只包含 `_id`、`fileID`、`fileType`、`createdAt`、`updatedAt`。

## 一致性与失败处理

- 图片先上传、记录后写入。若记录写入失败，客户端尝试删除刚上传的文件，避免孤儿文件。
- 同内容的并发保存可能产生两个上传文件，但确定性记录 ID 保证数据库只保留一条作品记录；云端清理最终未被记录引用的替换文件。
- 列表读取失败不清除登录状态，只显示重试提示。
- 登录取消时不生成、不上传、不跳转。

## 测试与验收

自动化测试覆盖：

- 内容指纹稳定，视觉字段变化会改变指纹，时间与临时路径不影响指纹。
- 生成成功后上传并保存记录；保存失败仍保留本地生成结果并清理新上传文件。
- 云端首次新增、相同指纹更新且不新增、不同用户隔离、伪造 OPENID 无效、旧文件清理和集合自动创建。
- “我的制作”仅查询当前用户、倒序限制 50 条。
- 个人中心入口登录成功后跳转，取消时不跳转。
- 列表正常、空状态、失败重试及点击图片预览。

手工验收：首次生成后在“我的制作”出现一条记录；相同配置再次生成仍为一条且排到最前；改变文字或素材后新增一条；切换另一个微信用户不可看到前一用户作品；点击作品可查看大图。

## 部署要求

- 重新上传部署 `quickstartFunctions` 并选择云端安装依赖。
- 确认云函数具有数据库和云存储读写权限。
- 建议在 `creations` 集合创建 `_openid + updatedAt` 查询索引。
