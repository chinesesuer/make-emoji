# 微信用户登录与功能门禁设计

## 目标

为小程序增加普通用户微信登录能力。用户可以匿名浏览素材和工具页面，但上传、生成、转换、保存、收藏及个人数据相关操作必须登录。未登录用户点击受保护功能时，系统发起微信授权；登录成功后自动继续原操作。

## 范围

### 无需登录

- 浏览首页素材、切换素材分类和编辑步骤。
- 切换底部 Tab、查看 GIF 工具与更多工具列表。
- 浏览各工具页面中不产生用户数据的说明和设置项。

### 必须登录

- 首页“存表情”中的生成和保存操作。
- 视频转 GIF 的选择/更换视频、上传审核、转换与保存操作。
- 多图转 GIF、GIF 加文字等 GIF 工具中的选择素材、上传、生成、转换与保存操作。
- DIY 表情、表情混合、九宫格切图等工具中的素材选择、生成与保存操作。
- 个人中心的“我的制作、我的收藏、我的邀请、免广告”等用户功能。

## 方案

### 客户端公共登录服务

新增 `miniprogram/utils/auth.js`，作为普通用户登录的唯一入口，提供以下接口：

- `getCurrentUser()`：读取已缓存的用户资料。
- `isLoggedIn()`：判断本地是否存在完整登录态。
- `ensureLogin()`：验证微信会话；未登录或会话失效时发起授权并完成云端登录。成功返回用户对象，取消或失败返回 `null`。
- `requireLogin(action)`：返回包装后的异步函数。登录成功后执行 `action`，登录失败或取消时不执行。
- `logout()`：清除本地普通用户登录信息。

客户端缓存键使用独立命名空间，不复用管理员的 `adminToken`。缓存内容包括 `openid`、昵称、头像地址和登录时间。缓存只用于界面状态和减少重复授权，不能作为云端可信身份。

为避免连续点击产生多个授权窗口，`ensureLogin()` 内部复用同一个进行中的登录 Promise。登录完成或失败后清除此 Promise。

### 微信授权流程

未登录用户从受保护按钮发起操作时：

1. 由该次用户点击直接调用 `wx.getUserProfile`，显示微信授权提示。
2. 授权成功后调用 `wx.login` 获取临时登录凭证。
3. 调用 `quickstartFunctions` 云函数，事件类型为 `login`，并提交授权得到的昵称和头像。
4. 云函数通过 `cloud.getWXContext()` 获取可信 `OPENID`，在 `users` 集合中创建或更新用户。
5. 客户端缓存云函数返回的用户信息，并继续执行用户原先点击的操作。

用户拒绝授权时不执行原操作，并用轻提示说明“登录后才能使用该功能”。网络或云函数异常时显示“登录失败，请稍后重试”，原操作保持未执行状态。

### 云端用户接口

扩展 `cloudfunctions/quickstartFunctions/index.js`：

- 新增 `event.type === 'login'` 分支。
- 从微信上下文读取 `OPENID`，拒绝缺少 `OPENID` 的请求。
- 对昵称和头像字段进行长度及类型清洗。
- 按 `_openid` 查询 `users` 集合；存在则更新资料和 `lastLoginAt`，不存在则创建记录并写入 `createdAt`。
- 返回 `{ success, user }`，其中 `user` 包含 `openid`、`nickName`、`avatarUrl`。

云端不信任客户端传入的 `openid`。管理员登录保持原状，与普通用户登录互不影响。

### 功能入口接入

各页面不复制登录实现，只在受保护的事件处理函数开头调用 `ensureLogin()`：

```js
const user = await ensureLogin();
if (!user) return;
```

登录检查发生在媒体选择器、上传、生成或保存开始之前，确保未登录用户不会先选择或上传文件。登录成功后函数继续向下执行，因此用户无需再次点击按钮。

首批必须覆盖：

- `pages/index/index.js`：`generateEmoji`、`saveGeneratedImage`。
- `pages/gifVideo/gifVideo.js`：`chooseVideo`、`startConvert`、`saveGif`。
- `pages/gifImages/gifImages.js`：`chooseImages`、`generateGif`、`saveGeneratedGif`。
- `pages/gifText/gifText.js`：素材选择、生成及保存入口。
- `pages/emojiMixer/emojiMixer.js`：生成/保存入口。
- `pages/diyEmoji/diyEmoji.js`：生成/保存入口。
- `pages/gridSlice/gridSlice.js`：`chooseImage`、`generateTiles`、`saveAll`。
- 后续新增的上传、生成、转换、保存和用户数据入口也必须使用该公共门禁。

### 个人中心

个人中心通过 `getCurrentUser()` 显示登录态：

- 未登录：默认头像、文案“点击登录”，隐藏虚构 UID。
- 已登录：显示微信头像、昵称和普通用户标识。
- 点击用户卡片时调用 `ensureLogin()`；登录成功后立即刷新页面数据。
- “我的制作、我的收藏、我的邀请、免广告”等入口先调用登录门禁，再显示现有的“即将上线”提示。

## 状态与错误处理

- 微信会话有效且存在缓存用户：直接通过，不重复弹窗。
- `wx.checkSession` 失败：清除旧缓存并重新授权登录。
- 用户拒绝或取消：不执行功能，不产生上传或生成任务。
- 登录请求并发：所有调用等待同一个登录 Promise。
- 云函数或网络失败：清除不完整状态，显示失败提示，允许用户再次点击重试。
- 用户登录后返回页面：个人中心和受保护功能读取同一份缓存状态。

## 测试与验收

- 公共登录服务单元测试覆盖：已有有效登录态、会话失效、首次授权成功、用户取消、云端失败、并发复用。
- 静态接入测试确认所有约定的上传、生成、转换和保存函数调用登录门禁。
- 云函数测试确认用户首次创建、再次登录更新和不信任客户端 `openid`。
- 手工验收：
  - 未登录点击首页生成，出现微信授权；成功后自动生成。
  - 未登录点击视频选择，成功登录后自动打开视频选择器。
  - 取消授权后不打开媒体选择器、不上传、不生成。
  - 登录后切换多个功能不重复授权。
  - 个人中心登录前后头像昵称正确切换。

## 发布要求

- 更新并重新部署 `quickstartFunctions` 云函数，选择云端安装依赖。
- 云环境需允许云函数创建和更新 `users` 集合记录。
- 普通用户登录与管理员后台登录必须分别验证，避免互相影响。
